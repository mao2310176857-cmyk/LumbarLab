里面有一份 `给队友的说明.md`，可以直接发她。

## 四、常见问题速查

| 症状 | 原因 | 怎么办 |
|---|---|---|
| 队友访问 403 | 少了 `--allow-lan` | 重启服务加这个参数 |
| 队友访问不了 | 不在同一个局域网 / IP 变了 | 用手机开个热点让两台电脑都连，或查新 IP |
| 网页连不上串口 | 串口被占 | **关掉串口助手、Arduino IDE 串口监视器** |
| 电机一个方向不动 | 继电器接线 | 敲 `1` / `2` 单测，看哪个继电器灯不亮 |
| 灯常亮 | 固件版本旧 | 重新烧 `outputs/LumbarLab_8ch_板端固件.ino` |
| 6 号传感器没反应 | A5 没接好 | 不影响路演，算法会忽略它 |

## 六、还没解决的（不阻塞路演，但要知道）

**① 6 号传感器（A5）没信号**

实测 A5 恒为 0V，其他七个都正常。可能是没接、接错、或者传感器坏了。
硬件那边接好后，`config/ignored_zones.json` 里的 `ignore` 保持为空数组，
固件里的 `SENSOR_IGNORE` 保持全 false，就自动启用了（不用重烧）。

**② 左右映射与网页标签相反**

| 通道 | 你的编号 | 网页显示 |
|---|---|---|
| A0 | #1 右腿 | 1 左前座 |
| A1 | #2 左腿 | 2 右前座 |
| A4 | #5 腰右 | 5 左腰 |
| A6 | #7 腰左 | 7 右腰 |

**1↔2、5↔7 反了**，3/4/6/8 一致。
队友的算法只看各区的均值和差值，**不影响控制逻辑**，但显示上会让人困惑。
要改的话告诉我按谁的编号为准，我改 `config/zones.json`。

**③ 阈值是临时值**

`config/tuning.json` 里现在是：
```json
{ "max_waist_level": 255, "min_waist_contact": 1, "min_seat_occupied": 1 }
```
这是为了让手动测试能跑而放宽的。**路演时能用**，但真实坐姿下的数值需要重新标定。
队友那 0.8 秒的数据有效期判定线是安全契约，不能动。
