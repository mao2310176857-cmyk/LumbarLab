# 智能腰靠 Demo 验收流程

本流程先验证模拟模式下的完整操作链，再验证只读传感器接入。每次从“自然坐姿”、停止动作和新个人参考开始，有助于复现实验。

## 1. 启动与显示

在项目根目录运行 `python run.py --no-browser --port 8765`，打开 `http://127.0.0.1:8765`。

本机 PATH 中的 Python 为 3.9.1，可运行 `.\start_windows.bat --no-browser --port 8765`，由启动脚本选择现有的 Python 3.12 运行时。

预期：八区读数持续更新，1、2 为座面前部，3、4 为座面后部，5、6、7 为活动腰托，8 为上背。模拟行程位于 0—100%；串口未连接时不应显示真实执行器已连接或已运动。未保存个人参考时，自动开启应被拒绝并提示先记住支撑。

## 2. 手动与参考

1. 点击一次“推出一点”，观察行程小幅增加并自行停止；点击“收回一点”，观察行程小幅减少并自行停止。
2. 动作期间点击停止，确认随后的行程不再继续变化。自动运行期间发起手动动作，确认自动让出控制权。
3. 保持自然坐姿，点击“记住当前支撑”，等待约 3 秒。预期出现参考范围，腰部 5、6、7 均有有效接触。
4. 采集参考期间切换“离开座椅”“腰部脱离”或“异常数据”，预期采集失败或取消，不能把这段读数作为新参考。
5. 用不稳定的真实数据重复时，预期提示保持稳定后重新采集；不要用反复切场景的平均值冒充舒服状态。

## 3. 自动跟随与稳定

1. 自然坐姿下完成参考，打开“自动跟随支撑”开关；初始读数在参考范围内时应保持。
2. 切换“身体前倾”并保持。接触减弱持续超过设定时间后开始前顶；行程与读数随动作变化，接触进入参考范围内部后停止，随后留出停稳时间。
3. 回到“自然坐姿”或切换“身体后靠”，观察偏强时回退。回退后仍保留接触，不应持续退到零。
4. 切换“向左偏坐”，检查 5、6、7 的不同响应，确认单个测点偏高时也能触发回退建议。整体偏弱与局部偏强冲突时应保持并提示手动调整，不应反复前顶/回退。
5. 迅速切换“身体前倾”后回到“自然坐姿”，短暂变化不应立即导致连续调整。处在边界附近时，不应每帧交替前顶/回退。
6. 关闭自动开关；变化场景后仍应暂停。明确再次开启自动后才继续。

## 4. 异常停止与明确重启

对下表每种情况独立操作：先自然坐姿建立参考并开启自动，然后注入异常，再恢复自然坐姿。

| 场景 | 预期行为 | 恢复后 |
|---|---|---|
| 离开座椅 | 停止并暂停，提示无人接触 | 保持暂停 |
| 腰部脱离 | 不把零接触当作支撑不足继续前顶；停止并暂停 | 保持暂停 |
| 信号掉线 | 最后一帧超时后停止并暂停，界面提示陈旧/中断 | 保持暂停 |
| 异常数据 | 无效数据停止并暂停 | 保持暂停 |

恢复有效且在座、有腰部接触的数据后，点击开启自动才可继续。持续点击手动前顶也不能越过模拟行程上限；手动回退不能越过下限。

## 5. 记录、反馈与回放

1. 点击“开始记录”，完成“自然坐姿 → 身体前倾 → 身体后靠 → 关闭自动”流程，中途依次留下“支撑偏强”“刚刚好”“支撑偏弱”反馈。
2. 点击“停止并保存”，确认列表出现本次实验，样本数大于零。
3. 点击记录的“回放”，检查时间轴能定位压力、动作、位置和反馈；进入回放会先暂停实时自动，拖动/播放历史记录不驱动设备。点击“返回实时”后仍需明确开启自动。
4. 下载 JSON，确认包含 `schema_version`、`parameters`、`reference`、非空 `frames` 和 `events`，反馈带有发生时间。
5. 退出并重启服务，确认本次已结束记录仍可从列表打开。

记录的是控制建议和模拟位置；只有硬件提供的位置反馈才可以解释为真实执行器位置。

## 6. 默认配置下的只读串口联调

硬件准备与固件核对见 [hardware.md](hardware.md)。

1. 安装 `pyserial`，关闭占用同一串口的串口监视器，选择设备及 `2000000` 波特率。
2. 先查看 16×16 矩阵，在不同实物区域逐处按压，记录发生变化的矩阵索引。完成 `config/zones.json` 的明确映射后重新连接。
3. 没有映射或 `base=0` 时，确认界面不能把输入当作可自动控制的有效八区参考。
4. 无人接触时执行电脑端空载归零；坐下调整后另行记住支撑。检查这两个功能不会互相替代。
5. 保留原始数据、逐区变化和帧序号检查结果。断开 USB，确认数据超时且建议停止；重新连接后不自动重启。
6. 核对串口模式的所有动作都只是电脑端建议，不产生电机运动命令。实际电机联调要等指令、方向、限位、急停和位置反馈接口明确后单独实现。

真实适配器实现后的硬件验收，另按 [接入指南](HARDWARE_INTEGRATION.md) 执行并留存实测记录。

## 验证范围

自动化验证运行 `python -m unittest discover -s tests -v`。人工验收以实际观察结果为准，执行后记录日期、软件版本、参数、通过项与失败项；本文是验收步骤，不代表这些步骤已经在实物上通过。
